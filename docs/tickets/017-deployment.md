# 017: Deployment

**Depends on:** 013, 014, 015

Deploy with Docker Compose on a VPS behind Tailscale, per the Default in SPEC §7. Create the bundle repo on first run, and push it to a private remote after each commit, retrying on failure without blocking writes.

**Done when:** the owner can use it from the van on their phone, and rebuilding on a new server from the remote has been tested.
