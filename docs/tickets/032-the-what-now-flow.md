# 032: The what-now flow

**Depends on**: 031

"What now?" was four lists of cards. It answered the question, but it gave no sense of where you had got to: the same screen whether you had just finished a job or hadn't touched the van for a month.

Draw it as a flow, the way a build pipeline draws itself. The last few steps the log records come first, newest at the top, one step per task, ticked. Then the work you could start now, running off the same spine, with the one to start on picked out and given a bit of shine. The other groups — ordering, deciding, waiting for a delivery — stay below, quieter.

The log already links to the task each entry is about, so the steps are the record of the work, not a second copy of it.

**Done when**: What now opens with the last few steps you ran, flows into the tasks you can start now, and points at the one to start on.
