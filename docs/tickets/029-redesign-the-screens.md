# 029: Redesign the screens

**Depends on:** 028

The app works, so now it can be made good. Nothing about the data changes: the same screens, the same information, shown with a proper hierarchy and enough character to be worth opening.

Give every screen a header that says where you are and offers the one thing you might do next. Replace scattered words like "Not started" and "Blocked" with a single state pill used the same way everywhere. Let Home be a dashboard — where the project stands, what to do next, what's on order — instead of a list that repeats What now. Put the filters on What now in one scrolling row rather than three wrapped ones. Make the chat the centre of the app: the nav tab wears the accent colour, every screen offers a way in, and the task screen keeps "Tell it what you've done" in reach while you read. Give the shopping list a spend card instead of two bare numbers.

**Done when:** every screen has a clear header, one type scale, one way of showing state, and the chat is the obvious thing to reach for.
