# 028: Chat-first interface

**Depends on:** 015, 018, 019

The screens read the project; they don't change it. Everything that records work — state, progress, where something was left, what arrived — happens by talking to the AI. "I've ordered the PIR board" is enough, and the AI works out what that means.

Remove the state buttons from the task screen, the shopping screen and What now. Remove the progress slider and the current-state editor. Keep the taps that aren't work: approving a proposal, undoing a change, and confirming a measurement, which only the owner can do.

Every screen keeps a way into the chat with its context, so telling the AI about something is one tap away.

**Done when:** there is no button anywhere in the app that changes a task's state, progress or current state, and saying what you did in the chat updates the plan.
