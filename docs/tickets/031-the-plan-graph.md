# 031: The plan graph

**Depends on**: 030

The home screen was a list of areas, and the task tree was a tree. Both are the same thing seen badly: a project is a graph of work, with the parts hanging off the areas and the areas waiting on each other.

Make the plan a graph. One screen, at the root of the rail, showing the areas and the work under them as nodes with edges between them. Tap a node and it opens up, in place, to show what it waits on, what it unlocks and where it currently stands. The tree you get by tapping a node's chevron is the shape of the work; the dashed curves are the dependencies.

The old home screen and the old task tree go away. The plan replaces both.

**Done when**: the plan is the first thing the rail opens, it draws the areas and their work as nodes with edges, tapping a node opens its details in place, and there is no separate home screen or task tree left.
