# 054: A new chat

**Depends on**: 053

Once a conversation was open there was no way to leave it for a fresh one. The drawer kept the same session until the page was reloaded, so a new subject carried the whole of the last one's history with it.

Now the chat header has a **New chat** button, shown once there is a conversation to leave. It clears the screen, keeps whatever task the chat is about, and lists the old conversation under Recent chats. The new session isn't created until the first message is sent, so tapping it and not writing anything leaves nothing behind. It is disabled while the AI is replying.

**Done when**: a chat can be left for a new one in a tap, and the old one can still be found.
